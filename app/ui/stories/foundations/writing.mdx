# Writing

The interface speaks like a helpful clerk at the counter: short, concrete, and in the person’s terms, not ours.
Every visible string goes through i18n with keys in all four locale files. Review copy with the **Language** toolbar.

## Actions and their echo

Buttons are verbs that name the result. The toast that follows uses the same word.

## Errors

Say what happened and what to do next, in the interface’s voice. No apologies, no “Oops”, no error codes on their own.

## Empty states

Invite the first action with one line and one button. A filtered list that comes up empty only says nothing matches.

## Mechanics

- Sentence case everywhere, including buttons, table heads and page titles.
- No trailing colons on labels. No “click here”. No arrows in labels.
- Keep Peppol jargon (SMP, access point, UBL) out of the main path; explain it where it can’t be avoided.
- References and ids are shown exactly as stored, in tabular figures.
- `npm run translations:sort` keeps the locale files sorted; `npm run lint:translations` checks that every key exists in all four.
